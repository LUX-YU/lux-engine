# EC1 S2：实际能力闭包

本批保留原提供者，新增的组合值只有显式的领域引用，不提供 get<T>() 或 Application 借用。

- SessionActivities：SessionStore、SaveService。内置 History 命令和插件使用同一组合。
- ProjectActivities：ProjectStorage、WriteCoordinator、ExecutionRuntime。源读取继续 captureSource；任务继续 TaskScope。
- WorkbenchAccess：dispatcher、ViewHost、CommandRegistry。CPU 窗口不要求 RenderRuntime 或 LLVM。
- 纯登记 contribute 保留；显式 activate 在应用提供者和桌面已存在后运行，贡献安装仍经同一原子批次。没有请求的组不传入；缺少必需组在调用插件前拒绝。
- 激活状态由实际贡献闭包／工厂持有；外部 CodeLease 包围闭包与其捕获的析构。激活不能开启没有已登记 owner 的工作；活动任务结果仍由原 TaskScope、Session、保存服务接收。没有额外激活管理器。
- 扩展 ABI 升级 V8，Runtime ABI 不改。登记计数与激活计数各自验证。
- editor_extensions 去除内置工具构造算法；editor_builtin_contributions 是实际内置装配编译单元，与扩展核心分离。
- scene_control_api 提供两类真实开放 UI 工厂描述，头不含具体 View 或 GPU。现有场景控件实现继续在 scene_ui；该 API 是独立插件实际需要的编译边界。

S2 不宣称内容路由已经开放：Manifest 与内容关联在 S3 删除闭合表之后才成立。最终 SDK 验收需验证独立资产、自由 Pane 和真实会话保存消费者，不以以上声明代替运行结果。
