## Implemented contract

- `ScriptAbilityDescription` is the canonical, language-neutral descriptor. Stable contract/method identities,
  schema version/hash, method kind, receiver kind, value ABI and lifetime metadata are generated from an explicit
  owner-side declaration.
- Receiver v1 is limited to `NONE` and `PROVIDER_INSTANCE`. Generated provider concepts reject incompatible providers;
  generated binders borrow an already-created object and never construct, destroy, discover or share-own it.
- `SimulationBuilder::publishScriptAbility()` accepts only the currently installed System instance, records owner
  identity for diagnostics, rejects a second default provider, and publishes the existing S1 capability shape.
- Simulation clears the publication view before reverse-order System destruction. ScriptSystem shutdown/unmount does
  not own or destroy providers.
- The generated C++ facade, Lua projection and provider-free FlowForge node catalog all consume the same contract and
  preserve the same contract ID, method ID, schema, method kind and lifetime metadata.
- `BORROWED_STEP` is rejected at an async Ability boundary. Lua intentionally omits borrowed-result and async methods;
  FlowForge retains the metadata for later S3 validation without implementing lowering.
