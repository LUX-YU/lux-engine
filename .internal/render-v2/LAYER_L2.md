# L2 — Feature / Graph / Native decoupling

Parent: c5d66814fb3e2e2b4164b4b55dcc88a1e5df3819. This is an internal implementation gate, not final independent V.

FeatureDescriptor is metadata only. Assembly owns graph construction/audit; Command validation exists solely at registration. FeatureInstanceView borrows Descriptor/GraphOps/config for one call. ProgramContribution separates immutable Pass programs from Effect-owned binding arguments; same-key equal arguments are accepted and unequal arguments rejected. No long-lived owner was added.

Graph local IDs moved to Core without changing layout. ShaderInterface/SpirvArtifact live in Data, PassProgram in Graph, and GraphStorageBinding/StorageArgument in Resource. Native compile consumes Definition, the original Analysis, bindings, programs and target. It resolves keys cold, rejects duplicate/unknown programs and malformed bindings, and never calls Feature callbacks or analyze. NativeResourcePlan remains the original physical recipe.

Base Native contains Device/Memory/Queue/Transfer/GpuWork/Retirement/Compiler/Execution. The real extensions component contains Texture Storage/Commands and GPU Command completion adaptation. Runtime uses extensions through its explicit dependency; a direct Graph consumer links base only, executes real GPU clear/readback, and also runs from a relocated installed SDK. Clone borrows source allocation plus LastUse at preparation; Texture no longer mutates Transfer private fields. Accepted-submit LastUse merging and candidate leases are unchanged.
