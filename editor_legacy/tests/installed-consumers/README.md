# Frozen Editor SDK consumers

These fixtures belong to the previous Editor. They are reference source only and are not configured,
installed or exported by Framework v2. Reproduce their original paths, toolchain and outcomes from the
historical implementation commit; do not retarget their old interfaces to the current foundation.

Current Object, UI, services and runtime-only spatial consumers remain under `cmake/installed-consumers`.
The complete current framework consumer is `editor/tests/installed`.
