```yaml
- current: modules/core/extension_abi (deleted)
  target: engine/extensions/api
  action: MOVE_DELETE
  owner: extensions
  document: "02,06"
  status: DONE
  compatibility:
```

```text
status=DONE → current path/symbol 不得存在
status=COMPAT → 只允许 forwarding/alias，不允许实现
status=PENDING → legacy report 允许但不能增长
```
