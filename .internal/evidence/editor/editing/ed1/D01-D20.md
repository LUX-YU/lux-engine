# ED-1 决策到实现映射

本表对应交付测试 bd8f634f 及其后资格驱动修正，最终 clean source 身份见 README.md。
原始要求在 design-input.zip；本次操作授权来自用户实施请求。
路径均相对仓库根，逻辑结果见 acceptance-results.csv。

| 决策 | 实际落点与验证 |
|---|---|
| D01 一份内容一条历史 | EditingFixtures.hpp 的 TextSession/RecordSession 各自拥有唯一 EditHistory，路由借用 session；C10–C13、R01、R14。真实业务尚未迁移。 |
| D02 业务自定义操作 | editing 核心仅 EditOperation/PreparedEdit 抽象；Text/Record 仅在 test 和 installed-consumers；I01/I04。 |
| D03 提交顺序 | EditHistory.cpp execute/replay 的显式 phase；先 apply，再更新 entries/current/revision，随后 publish、notice、collect；F09/F12/F13。 |
| D04 失败原子性 | execute 在业务 apply 前完成标题、裁剪规划和 prepare；TestChecks.hpp 对拍模型、选择、memento、输入地址、条目和 snapshot；C15/C21/F01–F08。 |
| D05 失败保留所有权 | EditHistory::execute(EditOperationPtr&)；成功 CHANGE 才移动，NO_CHANGE 在 RECLAIMING 释放；C20–C23。 |
| D06 no-op 保留 redo | NO_CHANGE 分支发生在任何历史修改前，不 publish；C16–C18/C22。 |
| D07 初次 base 与回放方向 | execute 检查 baseState；replay 使用 Entry.before/after 与 FORWARD/BACKWARD；C08/C10/C13、F07/F08。 |
| D08 内容身份与版本分离 | DLL 内 out-of-line CAS 身份发行器；serial 只对新提交增加，revision 对内容变化增加；C02/C19、L08 独立进程、跨 DLL consumer。 |
| D09 保存票据 | beginSave/finishSave 只处理 state/request/outcome，无 IO；S01–S09、L06。 |
| D10 owner 与忙碌门 | Impl::check、PhaseGuard、RouteGuard；正常拒绝使用结构化错误，不依赖 assert；C05/F11/R09/R13；测试显式 /UNDEBUG。 |
| D11 选择先于通知 | RecordSession::Plan::apply 同时 swap records/selected；C11 两个独立观察者读取一致模型、选择和历史。 |
| D12 清理不回放 | retireAll/collect、clear/close/析构只销毁恢复资源；C14/C20/C23、F13、L06/L09；SSO 标题在 entries 最终位置借用。 |
| D13 业务暂存组合 | RecordSession 的 map 与 selection 由一个 Plan 提交；核心未增加 macro/merge。恢复的 Graph compound 原子回归仍测试旧 Graph 权威。 |
| D14 业务预览 | Session target 管理 preview，undo 可返回 TRANSIENT_CANCELLED，redo 被阻止；R07/R08；核心未增加 recordAlreadyApplied。 |
| D15 非拥有路由 | ActiveEditHistory 预留 target 指针槽；HistoryTargetRegistration 用 weak control，close 失效旧控制块；R01–R05/R10–R12。 |
| D16 执行重验 | invoke 在 RouteGuard 内调用 historyId/historyView 并检查 availability；Controller 捕获原 handle，failed 携带 owned EditFailure；R14–R17 的真实 CommandRouter。 |
| D17 显式配额 | 工厂存储溢出检查、EditPreparationBudget、条目 charge、最小前缀裁剪与计数饱和；C03/C04/F04/F05/L01–L09/R03。 |
| D18 无旧栈包装 | Inspector/Graph 生产代码没有改用新历史；仅定向恢复测试和 BUILD_TESTING 接线；未向 EditorApplication 装配全局 Undo。 |
| D19 配置与证据分开 | RelWithDebInfo + EDITOR；诊断开关 ON 验证故障，OFF 安装与计时；qualified 原始日志绑定 clean clone 和提交，早期失败另存。 |
| D20 不扩展范围 | 保留初次旧依赖/dirty 工作区失败日志；改用仓内既有资格记录指明的 q2 依赖。未升级依赖或修改 modules/Script/Scene 生产代码。 |
