## 实施

1. `RGBuilder.cpp`：未解析的命名纹理引用保留“隐式全数组”标记，避免未知维度时写死一层。
2. `RenderGraphCompiler.cpp`：在有效资源索引内重定向引用，再用真实 description 解析隐式层数。
   显式单层和子范围不被扩展，公开类型布局不变。
3. `ForwardMeshFeature.cpp`：Forward 采样显式依赖 `MeshShadowDraw`，保留已有上传依赖。
   不依靠 Editor 调整 Feature 注册顺序，不更改通用依赖分析器的读写语义。
4. Render 模块新增 16 个逻辑用例，覆盖 read/write/readWrite/inputRead、2D、1/4/7 层数组和显式范围。
   GPU 测试检查真实编译图的执行顺序，并在报告错误前关闭全部 owner。
5. Editor GPU 测试新增 `viewport_input`：真实 UiInputEvent → Pane → SceneView → GPU 图像回读。
   现有 UI 生产实现通过这些用例，未为同一问题重写实现。
6. Editor 测试构建复用现有 `lux_scene_seed` cooker 生成输入，不复制 cooker 实现。
   统一资格脚本增加三个 shared View 变体和 viewport_input；显式设置 configure 时的安装前缀，
   避免现有 toolset 的绝对安装目的地绕过 `cmake --install --prefix`。
