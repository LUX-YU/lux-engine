## 开放轴与封闭轴

开放：源资产类型、Session 工厂、内容/视图关系、保存策略、命令、扩展激活、组件/Feature 要求。
封闭：磁盘标签解码、有限请求与事务阶段、平台分支、旧格式只读映射。后者不改造成插件接口。
五层不变，不新增 SDK 聚合库、万能 Editor 接口、运行时、线程池、服务定位器或管理器。

## 骨骼与公共能力

源码已存在 `lux::rdesc::Skeleton`、`SkeletonAsset`、稳定 `lux.skeleton` AssetTypeId 以及
`TAssetSerDeser<SkeletonAsset>`。S6 使用这套数据/codec；仅编辑名称与允许的姿态属性，不重排
parent_index、不改变网格索引或逆绑定语义。`Bone_t` 在修改闭包中正名，三安装 include 同步。
插件目标消费者只能用安装公共能力，内置工具必须走同一入口。最小读资产、自由 Pane、无 UI
编辑保存分别验收，不能仅用一种完整宿主样例替代。
