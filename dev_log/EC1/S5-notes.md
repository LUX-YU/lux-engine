- Existing `objects` did N*S membership calls then repeated identity/schema/membership lookup for each present component. A local list of populated schemas removes empty-pool probes; direct capture of an already validated tuple removes the second lookup. The source gate and fixed registration owner span the traversal; no fallible callback lies between membership validation and capture. No removal of checks after codec callbacks in ModelCreationOperation.
- Existing copyOpaque is both the external freeze boundary and internal snapshot copying. External bytes must still copy (the existing mutable alias regression remains). Internal retention now accepts an actual SceneSource, shares only its admitted immutable byte blocks, and still charges all logical bytes. Metadata and component encode outputs remain owned copies. No caching of foreign `shared_ptr<const>` as if it proved immutability.
- Outliner fold keys become full author or Run object references (Session/History or Run/Instance/Entity generation), not displayed labels. Refresh makes N hash inserts and C membership queries, replacing C scans of N labels. Stable frames still perform no rebuild. The lookup counts stated here are algorithm bounds, not allocator instrumentation measurements.
- Model primitive dependency admission uses captured catalog.find(id), with expected magic checked. Current catalog revision is still checked before and after foreign component codecs. No change to asynchronous source ownership or source stamp.
